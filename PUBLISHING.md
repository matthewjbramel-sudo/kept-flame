# The Kept Flame — Publishing Checklist
The weekly flywheel, as a checklist. Nothing goes live without every box ticked.

## The loop
- [ ] Essay drafted (verdict first, practical, ~5–6 min read)
- [ ] Matches the 52-topic map sequence (no skipping ahead without reason)
- [ ] Content law scan (automated in build-site.py):
  - [ ] No explicit/pornographic terms — HARD BLOCK
  - [ ] No slurs — HARD BLOCK
  - [ ] No trademarked/property-linked terms (cyberpunk, Tron, Night City, etc.) — HARD BLOCK
  - [ ] No pasted copyrighted text (blockquotes >150 words flagged)
  - [ ] No real people's names
  - [ ] No spam/affiliate links (outbound links >10 flagged)
- [ ] Human review — nothing publishes without eyes on it
- [ ] Homepage rebuilt (build-site.py)
- [ ] Committed + pushed to kept-flame repo
- [ ] Verified live (HTTP 200 on the article URL)
- [ ] Cross-links checked (series siblings linked)

## Content law (standing)
Nothing explicit. No slurs. No pasted text. No real names. No spam.
Generic or invented words only — never trademarked terms.
Nothing publishes without review. Ever.

## Cadence
One essay per week. Buffer target: 4+ weeks banked at all times.
If buffer drops below 2, writing becomes the top priority.
